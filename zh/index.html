PawMinute 能做什么

比起显示时间，它更多是在记下你今天和宝贝一起做了什么。

01一粒一粒推的分针

分针是八粒饲料。每过 1 分钟，就走过去推一粒。

0279 种角色

狗狗和猫咪品种、绘画伙伴和其他伙伴。一开始从柯基和孟加拉猫中选一位。

03四位一起推

最多可以叫四位伙伴一起推，每位都可以起名字。

04它知道饭点

到了设定的时间，就走到碗前等着。喂完后请按“喂过饭了”。

05散步计时

出门前按开始，回来后按结束，就会留在今天的记录里。

06猫咪改为陪玩

如果主宝贝是猫，散步会变成陪玩，记录也按一起玩来算。

07抚摸

在角色身上摩挲，会冒出爱心并发出咕噜声。

08晚上睡觉

晚上 10 点到早上 7 点，会蜷在表盘下方睡觉。

09时钟待的地方

地毯、草地、木头、极简、夜晚，五种表盘任选。

10深色画面

浅色和深色画面切换，晚上不刺眼。

11宝贝的信息

记下名字、生日和照片。生日那天会戴上派对帽。

12每周记录

一眼看出本周吃饭和散步守住了几天。

13电脑桌面时钟

同一位伙伴浮在 Windows 桌面上对时。圆圈外面鼠标可以穿过。

14调整大小

桌面时钟可以拖动手柄或滚动滚轮来调整大小。

15勿扰

全屏看视频时，时钟会自动变淡并退到后面。

16休息提醒

按设定的间隔提醒喝水和伸展。照顾宝贝，也照顾主人。

17添加到主屏幕

在手机浏览器里添加到主屏幕，就会以脚掌图标像应用一样打开。

18只保存在设备上

没有账号。约定和记录只留在这台设备上，不会发送到任何地方。

也在桌面上陪着你

我们另外做了 Windows 版时钟。它没有窗口边框，浮在桌面上， 时钟圆圈外面鼠标可以穿过，不影响你手上的工作。

  • 拖动放到想要的位置，它会记住那个位置。
  • 大小把鼠标移上去，拖动出现的手柄或滚动滚轮。
  • 双击打开约定 · 装扮 · 记录窗口。和手机应用是同一个画面。
  • 提醒吃饭和散步时间会弹出 Windows 通知。

下载即将开放

安装

  1. 双击下载的文件。
  2. 出现蓝色窗口时，点“更多信息”→“仍要运行”。 这是因为 Windows 第一次见到这个程序。点一下小字的“更多信息”，才会出现“仍要运行”按钮。
  3. 安装位置保持不变，点安装。 不需要管理员权限。
  4. 时钟会出现在屏幕右下角。 任务栏右侧也会出现一个脚掌图标。

使用方法

  1. 拖动来移动。位置会被记住。
  2. 把鼠标移上去，拖动出现的手柄或滚动滚轮来调整大小。
  3. 在伙伴身上摩挲会冒出爱心。
  4. 双击会打开约定 · 装扮 · 记录窗口。
  5. 全屏看视频时，时钟会自动退到后面。
